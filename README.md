# 🚀 CyberFiction - 3D Interactive Website

A modern and immersive **3D scrolling website** inspired by the concept of the **Metaverse**. This project combines smooth scrolling, engaging animations, and interactive storytelling to create a visually appealing user experience.

## 🌟 Features

* 🎨 Modern UI/UX Design
* 🚀 Smooth Scrolling using Locomotive Scroll
* ✨ GSAP Powered Animations
* 🎭 Interactive Storytelling Experience
* 📱 Responsive Layout
* 🌐 Metaverse Inspired Theme
* 🎬 Scroll-Based 3D Effects

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* GSAP (GreenSock Animation Platform)
* ScrollTrigger
* Locomotive Scroll

## 📂 Project Structure

CyberFiction/

## 🎯 Project Overview

CyberFiction is an interactive web experience that explores the idea of storytelling in the Metaverse. Users navigate through animated sections using smooth scrolling effects while dynamic content and visual transitions create an engaging digital journey.

The website demonstrates advanced front-end animation techniques using GSAP and Locomotive Scroll to achieve a premium and immersive experience.

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/cyberfiction.git
```

2. Open the project folder:

```bash
cd cyberfiction
```

3. Open `index.html` in your browser.
